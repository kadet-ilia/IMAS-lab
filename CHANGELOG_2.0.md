# Изменения версии 2.0

## Межпрогонные области ±1σ/±2σ

- Удалена теоретическая аппроксимация `honest_noise_sigma / sqrt(N_active)`, ранее ошибочно выдававшаяся за межпрогонный разброс.
- Для каждого шага и каждого агрегатора сохраняется решение всех независимых прогонов серии Монте-Карло.
- Выборочное среднее и выборочное стандартное отклонение рассчитываются онлайн-алгоритмом Уэлфорда без хранения полного трехмерного массива результатов в памяти.
- Используется выборочное СКО с делителем `R−1` (`ddof=1`). При `R=1` ширина областей принимается равной нулю.
- Формируются пошаговые интервалы `mean ± 1s` и `mean ± 2s` для арифметического, доверительно-взвешенного и предлагаемого робастного методов.

## Изменения интерфейса

- На вкладке «Монте-Карло» добавлен график межпрогонной динамики решений.
- На вкладке «Один прогон» области накладываются на трассировку выбранного прогона после выполнения серии Монте-Карло.
- Добавлена кнопка «Рассчитать ±σ» непосредственно на графике одного прогона.
- Добавлены независимые переключатели отображения `±1σ`, `±2σ` и области допустимой ошибки `±δ`.
- Отображаются число прогонов `R` и правило расчета СКО `ddof=1`.
- Средняя робастная траектория по прогонам показывается отдельно от линии выбранного прогона.
- Результаты, рассчитанные для прежней конфигурации, автоматически признаются устаревшими и не накладываются на данные после изменения параметров.

## Экспорт и документация

- Пошаговая статистика включена в JSON результата серии Монте-Карло.
- Дополнительно создается CSV-файл `*_monte_carlo_trajectory.csv` с межпрогонными траекториями и границами областей.
- Справка дополнена формулами выборочного среднего, выборочного СКО и областей ±1σ/±2σ.
- Разъяснено различие между статистическим разбросом по прогонам, 95%-м доверительным интервалом итоговой метрики и областью допустимого отклонения ±δ.

## Проверки

- Выполнено девять модульных тестов Python.

- В Chromium проверено отображение двух статистических областей на вкладке «Один прогон» и трех областей на вкладке «Монте-Карло»; ошибок и предупреждений консоли не выявлено.
