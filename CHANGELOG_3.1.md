# Изменения версии 3.1

- Исправлен запуск Python-моста без установленных зависимостей.
- `start_gui.bat` и `start_gui.sh` автоматически создают `.venv` и устанавливают `requirements.txt`.
- Сервер автоматически выбирает интерпретатор из локального `.venv`.
- Добавлены `install_dependencies.bat` и `check_environment.py`.
- При отсутствии пакета `gui_bridge.py` выводит понятное диагностическое сообщение.
- В README уточнено, что установка пакетов и запуск должны выполняться одним интерпретатором Python.
