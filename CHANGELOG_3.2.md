# Изменения версии 3.2

- Выполнен полный аудит текстовых файлов проекта на корректность UTF-8.
- Windows-скрипты запуска переведены на ASCII-команды и окончания строк CRLF, поэтому их вывод не зависит от системной кодовой страницы.
- В `start_gui.bat` включены кодовая страница 65001, `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8` и запуск Python с параметром `-X utf8`.
- JSON-обмен между Node.js и Python выполняется явными UTF-8-байтами; стандартные потоки Python принудительно перенастраиваются на UTF-8.
- CSV-журналы сохраняются с UTF-8 BOM и разделителем `;`, что обеспечивает корректное открытие русскоязычных данных в Microsoft Excel.
- Для JSON и SVG, загружаемых из интерфейса, задан `charset=utf-8`; SVG получает XML-декларацию UTF-8.
- Добавлены `.editorconfig`, `.gitattributes`, `encoding_audit.py`, `check_encoding.bat` и модульный тест политики кодировок.
