# Протокол статистических проверок UP-30

Версия экспериментальной методики: 05.11.2026. Настоящий протокол относится к синтетическим моделям в ветке `remediation/imas-lab-scientific-integrity`.

## Показатели и единица статистического наблюдения

Единица наблюдения при сопоставлении двух режимов — **пара прогонов с общими экзогенными событиями** по одному номеру `run`. Разность `dᵣ = Yᵣ^(baseline) − Yᵣ^(alternative)` рассчитывается по одинаковым индексам прогона. Для абляции также рассматриваются разности при фиксированном агрегаторе, при фиксированном контроллере либо при изменении режима атаки.

Нулевая гипотеза для двустороннего парного sign-flip теста: распределение парных разностей симметрично относительно нуля и допускает обмен знаков в условиях H₀. Совпадение псевдослучайных событий **не доказывает** указанное условие. Его необходимо обосновывать для реального эксперимента отдельно.

При числе пар от 2 до 14 используется полный перебор `2^R` комбинаций знаков. При `R>14` используется воспроизводимое моделирование 4095 знаковых конфигураций, а p-значение определяется как `(b+1)/(B+1)`, где b — число не менее экстремальных статистик среди B перестановок. Нулевая парная разность для всех наблюдений имеет p=1. Для R=1 p-значение не определяется. В абляции вычисление p и CI дополнительно блокируется до получения хотя бы 10 совпавших пар.

## Семейства гипотез

| Обозначение | Семейство | Число заранее заданных сравнений | Исходная метрика |
| --- | --- | ---: | --- |
| A | Абляция E1 (контроллер, агрегатор, расписание атаки) | 26 | P(правильное решение) и покрытие решений |
| B | Распространение E3, 4 сценария × 2 режима снижения вероятности | 8 | P(опасного состояния) |
| C | Каскад E5, 8 стартовых агентов × 2 показателя | 16 | Ожидаемый ущерб и P(опасного состояния) |

В каждом семействе p-значения упорядочиваются по возрастанию, после чего применяется **пошаговая процедура Холма** для контроля FWER на уровне 0,05. Для ранга i=1,…,m скорректированное значение равно `p_adj(i)=max_{j≤i} min(1,(m−j+1)·p_(j))`. Коррекция Холма не требует независимости гипотез при корректной калибровке исходных p-значений. Семейства A, B, C контролируются **раздельно**; FWER относительно объединённого набора всех экспериментов не контролируется.

Поле `holmReject05` или `holmReject*05` относится только к тесту с откорректированным p-значением. В случае R=1 оно равно `null`, а не `false`, поскольку статистическая проверка не выполнялась.

## Доверительные интервалы

- Wilson 95% используется для долей исходов и имеет положительную верхнюю границу при нуле наблюдений.
- Парный percentile bootstrap 95% применяется к разности средних при сохранении индексной парности.
- ES95 оценивается по худшим 5% эмпирической вероятностной массы с дробным учётом границы; при `0,05R<10` выводится предупреждение о нестабильности хвостовой оценки.
- Показанные в интерфейсе 95%-е bootstrap-интервалы **не скорректированы на множественные сравнения**. Следовательно, совпадение ненулевого интервала со знаком эффекта само по себе не является свидетельством FWER-контролируемой значимости.

## Ограничения

Численные данные получены по синтетическим постановкам. При расчёте результатов используются фиксированные генераторы, но отдельные параметры защиты заданы скалярными коэффициентами, не воспроизводящими реальные алгоритмы защиты. Значение статистической значимости не доказывает практическую значимость, причинную применимость к реальным защищённым ИМАС или соответствие модели экспериментальным данным.

Подтверждающая экспертиза требует независимого обоснования гипотезы обменности знаков, калибровочных измерений, исследования мощности и достаточности R, проверки параметрической чувствительности и отдельного семейства гипотез для всех заявляемых публикационных выводов.
