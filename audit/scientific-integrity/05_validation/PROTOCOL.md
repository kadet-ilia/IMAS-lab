# Протокол научно-технической приёмки IMAS-lab, редакция 2026-11-06

**Статус документа:** программа и методика приёмки, **не** акт приёмки. Тесты в CI выполняет коллектив разработчиков; их успешное завершение не является подтверждением независимого научного рецензирования, эмпирической калибровки или пригодности к применению на реальном объекте.

## 2. Фальсифицируемые условия отдельно по экспериментам

**E1.** На каждом шаге равенство количества попыток, доставок, потерь, отклонений, просроченных и ожидающих сообщений; независимый пересчёт Beta/EigenTrust по наблюдениям; сохранение начальной топологии; обнаружение не раньше старта атаки. Внутренний тест не устанавливает, что синтетический сетевой трафик соответствует реальному протоколу.

**E2.** Все исходные наблюдения, пропуски и видимые признаки по каждому агенту; условные и безусловные вероятности решения/ошибки и их знаменатели; отсутствие использования скрытых флагов в прикладном весе. Для эмпирической калибровки необходимы реальные обозначения событий и эталонные метки.

**E3.** Воспроизводимость ориентированного графа, очагов и полной случайной таблицы для каждой пары, корректное применение коэффициента защиты, учёт зависимых пар, корректировка Холма для семейства сравнений. Отдельно требуется обосновать выбор распределения рёбер и вероятность реализации угроз.

**E4.** Независимая полная проверка каждого обработанного состояния, перечня переходов, фронта и остановки на лимите маркировок; вывод «недостижимо» допускается только после исчерпания очереди поиска в пределах заданного горизонта. Реализация не заявляет полной временной раскрашенной сети Петри общего вида: проверяется документированный ограниченный подкласс.

**E5.** Исходные восемь вершин, веса ущерба, 8-тактовая таблица случайных событий по каждому ребру, парные условия защиты, ES95 (дробная масса хвоста) и предупреждение при малом эффективном объёме хвоста. Реальные денежные потери и частоты каскадов не калиброваны.

**E6.** Исходно скомпрометированные агенты, трёхшаговое распространение по девяти дугам, все наблюдения, раздельные потери ошибочного решения и отказа, неизменные данные для (k=0\ldots3). Порог и усечение не выбираются по скрытому статусу нарушителя.

## 3. Статистическая проверка и правила публикации

- Для бинарных показателей используются 95%-е интервалы Уилсона. Для среднего при малом R выводится предупреждение о нормальной аппроксимации.
- Для E3/E5 решения по нескольким гипотезам принимаются **только** по `pHolm` в установленной семье сравнений. Приводимые 95%-е bootstrap-интервалы отдельных эффектов не обладают одновременным семейным покрытием.
- Парный тест перестановки знаков допускает интерпретацию при проверяемой либо научно обоснованной **обменности знаков** при нулевой гипотезе. Общие случайные события сами по себе её не доказывают.
- Рекомендуемое R для заданной ширины интервала — задача **точности**, а не универсальная мощность статистического теста. Априорная оценка мощности должна содержать обоснованные минимальный эффект Δ и долю дискордантных пар. «Наблюдаемая мощность» по полученному p не интерпретируется как независимое доказательство.
- При оценке ES95 (0{,}05R<10) результат обозначается как нестабильный; интервал Monte Carlo не покрывает неопределённость параметров модели и ошибку модельных предпосылок.
- Численные результаты после изменения версии научного ядра пересчитываются заново, старые JS/Python таблицы без оговорок не объединяются.

## 4. Формат независимой внешней выборки

Сценарии реальных наблюдений должны собираться вне механизма генерации синтетических реализаций. Для вероятностных проверок E1/E2/E3/E5/E6 можно сформировать JSON:

```json
{
  "schemaVersion": 1,
  "provenance": {
    "datasetId": "actual-independent-dataset-id",
    "sourceOrganization": "organization-providing-measurements",
    "collectionMethod": "documented measurement methodology",
    "collectionPeriod": "documented observation time window",
    "reference": "independent source citation or verified experiment protocol"
  },
  "observations": [
    {
      "studyId": "probgraph",
      "scenario": "test scenario with a fixed event definition",
      "metric": "dangerProbability",
      "recordId": "unique-independent-observation-id",
      "predictedProbability": 0.2,
      "observedOutcome": 0
    }
  ]
}
```

В приведённом образце все строки **иллюстративные** и не являются предоставленными измерениями. Запуск:

```bash
python validate_external_calibration.py independent_dataset.json calibration_report.json
```

Скрипт проверяет происхождение (наличие метаданных, но **не** достоверность автора), уникальность наблюдений, диапазоны вероятностей, рассчитывает Brier score, LogLoss, частоту событий с 95%-м интервалом Уилсона и калибровку по десяти интервалам прогноза; фиксирует SHA256 исходного файла. Независимая проверка достоверности первичных данных проводится специалистами отдельно; статус отчёта всегда `pending_review`.

E4 проверяется как задача достижимости, а не с помощью вероятностной калибровки; для него требуется независимая формальная спецификация и проверка состояния «опасно/неопасно» по эталонному графу переходов.

## 5. Критерий завершения работ и правило подписи

Разработчики могут утвердить акт **внутренней вычислительной готовности** после V1–V4; акт **независимой научной приёмки** разрешён только после V5–V8 и устранения критических замечаний. Запрещено автоматически проставлять в интерфейсе отметку «Научная достоверность подтверждена» по признаку прохождения CI.

Места для независимого оформления (пока не заполнены): ответственная организация; должность и квалификация независимых экспертов; утверждённая программа экспериментов; перечисление и происхождение исходных данных; условия применения; нарушения и исправления; идентификатор окончательного коммита; дата и подписи. **На дату составления подтверждения этих условий отсутствуют.**
