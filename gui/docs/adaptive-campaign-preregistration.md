# E1-А — фиксированный протокол независимых вычислительных исследований

**Статус:** заранее определённая программа для новых случайных реализаций. Она не подтверждает преимущество метода сама по себе. Протокол программы фиксируется в `src/adaptiveCampaignProtocol.js` и выводится до вычислений посредством `npm run adaptive:campaign:design`.

Версия программы: `e1a-campaign-1.0.0`. Аналитический модуль: `e1a-analysis-1.0.0`.
Объект: скалярное коллективное решение E1-А с общей историей доверия и изоляции (режим `estimator_only`).

## 1. Основная гипотеза, эталон сравнения и единица наблюдения

Адаптивный метод `adaptive_robust` сравнивается с **исходным невзвешенным усечённым средним** `trimmed_unweighted`, а не исключительно с арифметическим средним.

Для прогона r в фиксированной конфигурации c:
  Δ_{c,r}=RMSE_{adaptive,c,r}−RMSE_{trimmed,c,r},
где RMSE каждого метода вычисляется по принятым решениям за T тактов. Отказы учитываются отдельной долей покрытия, а не ошибочно подменяются нулевой ошибкой или истинным значением. Отрицательное Δ указывает на уменьшение ошибки адаптивного метода. **Первичная единица статистического анализа — независимый прогон r, не отдельный такт.**

Практически существенное различие фиксируется априори как |mean_r Δ_{c,r}|≥0,01 в единицах оценки. Этот инженерный порог не следует трактовать как гарантию практической полезности для любой конкретной ИМАС. Отдельно показываются вероятность правильного решения, покрытие, MAE, хвостовые ошибки и характер их изменения в разные фазы.

## 2. Основной факторный план

Фиксированы N=30, T=48, исходное симметричное усечение k=6, независимые фазы атаки и число византийских агентов f∈{3,6,9,12}. Число честных агентов превышает число византийских во всех ячейках. Сетевая модель отключена, число Sybil-идентичностей равно нулю, свидетельства используются из исходной модели E1.

**Факторы:** шесть временных профилей (постоянный, линейный, экспоненциальный, параболический, гиперболический, импульсный), три расписания, четыре значения f. Всего 6×3×4=**72 конфигурации**.

Профили в активной фазе:
- постоянный — интенсивность 2;
- линейный, экспоненциальный, параболический и гиперболический — от 0,2 до 3 по нормированной форме E1;
- импульсный — 2 атакующих такта и 2 такта перерыва, повторяемые от начала каждого разрешённого интервала активности.

Расписания на горизонт T=48:
- `single` — такты 9–24 (последующее восстановление 25–48);
- `sustained` — такты 13–48;
- `double` — интервалы 9–16 и 25–32 с паузой 17–24.

Статистическая серия: **30 независимых прогонов на ячейку**, всего 2160 прогонов. В каждой реализации все сравниваемые оцениватели получают одни и те же экзогенные предложения, условия доставки, историю доверия и изоляцию.

## 3. Независимая серия с заранее выбранными конфигурациями

Выбор конфигураций сделан **детерминированным правилом по индексу временного профиля до запуска новых прогонов**, без отбора ячеек по результатам разведочной серии. Для каждого из шести профилей выбираются два варианта: один с циклическим значением f и одним из трёх расписаний, второй с f=12 и следующим расписанием.

| Профиль | Первая конфигурация | Вторая конфигурация |
|---|---|---|
| Постоянный | `constant__single__f3` | `constant__sustained__f12` |
| Линейный | `linear__sustained__f6` | `linear__double__f12` |
| Экспоненциальный | `exponential__double__f9` | `exponential__single__f12` |
| Параболический | `parabolic__single__f12` | `parabolic__sustained__f12` |
| Гиперболический | `hyperbolic__sustained__f3` | `hyperbolic__double__f12` |
| Импульсный | `pulsed__double__f6` | `pulsed__single__f12` |

Новые прогоны используют отдельное семейство seed и не повторяют реализации основной серии: **100 прогонов на конфигурацию, всего 1200 прогонов**. Таким образом, для двух стадий установлены 3360 прогонов при неизменном математическом алгоритме.

Следует отметить, что другие результаты синтетического моделирования ИМАС анализировались ранее. Поэтому даже новая независимая серия не заменяет проверку на внешних данных и не может рассматриваться как полностью независимая постановка задачи исследования во всей научной работе.

## 4. Генерация случайных событий и отсутствие переиспользования

Индекс `ordinal` задаётся фиксированным порядком профилей, расписаний и f:
- основная серия: `seed=1100000000+4096·ordinal+271`;
- независимая серия: `seed=1800000000+4096·ordinal+947`;
- программная контрольная серия: отдельный набор seed начиная с 2000000000.

Индекс прогона r — отдельный аргумент детерминированного ключевого генератора E1. Рандомизация согласована для сравниваемых методов в рамках одной реализации. Валидация программы проверяет отсутствие повторения исходного seed между стадиями и ячейками.

Ключи контрольно-восстанавливаемого архива содержат криптографический SHA-256 **математического протокола** и **исходного кода критических вычислительных зависимостей**, включая базовую модель E1, адаптивный алгоритм, генератор атак, модели свидетельств и статистический модуль. После изменения вычислительного кода результаты не должны незаметно подмешиваться к прежним архивам.

## 5. Проверки достоверности вычислений

Для каждого прогона сохраняются RMSE, MAE, покрытие, вероятность правильного решения, вспомогательные показатели обратной связи и парные различия. Для каждого режима расписания раздельно вычисляются показатели предатаковой, активной, межатаковой и восстановительной фаз с учётом отсутствующих фаз.

Результат фазовой декомпозиции обязан пересчитываться в общий RMSE по тем же принятым решениям. Несоответствие тактов фаз либо расхождение метрик рассматривается как ошибка исполнения, а не округление для публикации.

Для двустороннего сопоставления используется парный `sign-flip`. Его применимость к нулевой гипотезе среднего парного эффекта требует **обменности знаков разностей**, которую синхронизация seed сама по себе не доказывает. В пределах каждого этапа p-значения по всем запланированным конфигурациям корректируются методом Холма; семейство включает 72 либо 12 тестов соответственно.

Дополнительно рассчитываются описательные 95%-е процентильные bootstrap-интервалы парных средних с ресэмплированием целых прогонов внутри конфигурации. Для равновесного среднего эффекта по конфигурациям используется стратифицированный bootstrap: отдельно перевыбираются реализации каждой фиксированной ячейки, после чего средние ячеек усредняются с равными весами. Интервалы являются **нескорректированными**, отражают лишь случайность имитационных прогонов и не учитывают неопределённость физической модели, а также не предназначены для доказательства универсальности метода.

Интерпретация эффекта предполагает совместный анализ величины, направления, доверительных интервалов, числа отказов и устойчивости результата по уровням f, профилям интенсивности и расписаниям.

## 6. Выполнение в тестовой ветке

Из каталога `gui`:

`npm ci`

`npm run adaptive:campaign:design` — подготовить фиксированную программу без расчётов.

`npm run adaptive:campaign:smoke` — три контрольные конфигурации, по два прогона; только проверка исполнимости.

`npm run adaptive:campaign:exploratory` — 72×30.

`npm run adaptive:campaign:confirmatory` — независимые 12×100; не использует наблюдаемые результаты основной серии для изменения конфигураций.

`npm run adaptive:campaign:all` — последовательно выполнить обе серии.

Каждая завершённая конфигурация сохраняется атомарно в `gui/adaptive-results/campaign/<fingerprint>/`: дизайн, первичные метрики по каждому прогону, контрасты, фазовые показатели, сводные JSON/CSV и контрольная трасса первого прогона. При повторном запуске конфигурация пропускается только после проверки её согласованности с зафиксированной программой и fingerprint.

Автоматический CI запускает только контрольную серию. Полные исследования выполняются отдельно по явному запуску, без изменения рабочего приложения и исходной ветки `IMAS_Lab`.

## 7. Критерии научной приёмки

1. Фиксированные факторы и наборы seed подтверждены машиночитаемым протоколом.
2. Не менее 2160 и 1200 завершённых прогонов в соответствующих сериях; неполная серия не называется завершённой.
3. Нет расхождений между первичными прогонными RMSE, фазовыми суммами и сводными показателями.
4. Сравнение адаптивного метода с обычным усечением остаётся первичным.
5. Для отрицательных, положительных и нулевых результатов публикуются оценки величины эффекта, интервалы и условия.
6. Выводы ограничены описанными синтетическими сценариями; до внешней калибровки и доказательства векторной устойчивости недопустимо утверждать универсальную безопасность или устойчивость ИМАС.
