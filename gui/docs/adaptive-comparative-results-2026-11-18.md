# E1-A: результаты трёх параметрических серий 18.11.2026

Статус: завершённые синтетические вычислительные исследования в ветке `IMAS_Lab_test`. Результаты не подтверждают универсальную киберустойчивость всей ИМАС. Полные первичные прогонные метрики доступны в артефактах GitHub Actions, а независимый аудит выполнен по ZIP-архивам.

## План и объём

- Основная серия: 72 сочетания закона интенсивности (6), расписания (3), числа византийских агентов (4), 30 повторений; 2160 модельных запусков.
- Риск-адаптация: те же 72 сочетания на новом семействе seed, два правила alpha на общих экзогенных событиях, 30 пар повторений; 4320 запусков.
- Поведенческая серия: 5 стратегий нарушителя × 3 модели свидетельств × 4 значения f × 2 правила alpha = **120 параметрических настроек**, 20 повторений на набор факторов; 1200 пар, 2400 запусков.
- Всего **264 параметрические настройки, 132 уникальных сочетания исходных факторов, 8880 выполненных запусков**; 5520 экзогенных реализаций по трём сериям с попарным сравнением двух вариантов alpha. В первом исследовании повторены ранее фиксированные seed, поэтому оно не является независимым подтверждением ранее опубликованного результата.
- Общие параметры: N=30, T=48, k=6, f ∈ {3,6,9,12}; нет Sybil и ограничений сети. Модель — скалярное коллективное решение в режиме `estimator_only`.

## Подтверждённые численные факты

**Основная серия:** разность RMSE(E1-A)−RMSE(невзвешенное усечение E1) = −0.00255988; 40/72 улучшений, 32/72 ухудшений; по закону интенсивности постоянный −0.011621, линейный −0.002448, экспоненциальный +0.006993, параболический +0.003357, гиперболический −0.006894, импульсный −0.004746.

**Рискоориентированное alpha:** ΔRMSE(risk_aware−adaptive)=−0.00080828, стратифицированный bootstrap 95% [−0.00082864;−0.00078811]; 47/72 улучшений и 25/72 ухудшений. По закону воздействия: постоянный +0.001885, линейный −0.000665, экспоненциальный −0.005057, параболический −0.003702, гиперболический +0.000906, импульсный +0.001784. При f=12 экспоненциальный −0.014161, параболический −0.010831, постоянный +0.004335. Средние RMSE: risk_aware 0.150787, adaptive 0.151595, комбинированное E1 0.150729.

**Новый поведенческий план:** ΔRMSE(risk_aware−adaptive)=−0.00108849, фиксированная bootstrap 95% [−0.001148;−0.001028], преимущество риск-адаптации в 32/60 базовых сценариях. Средние по стратегии: legacy +0.000244, coordinated +0.000143, stealth +0.000926, pulsed −0.006905, reputation_boost +0.000150. Без pulsed: **+0.00036564** [0.000311;0.000420] — исходное адаптивное правило в среднем точнее. При pulsed и f=12: **−0.02045294** [−0.021189;−0.019637]; при stealth и f=12: **+0.00198243** [+0.001716;+0.002238].

Средний RMSE новой серии: невзвешенное усечение E1 **0.153437**, комбинированное E1 **0.130649**, исходное адаптивное E1-A **0.137559**, risk_aware E1-A **0.136470**. Комбинированное E1 остаётся лучшим по среднему RMSE; условный выигрыш риск-адаптации не означает преимущество над всеми контролями.

## Границы применимости

1. Законы интенсивности и стратегии поведения — **разные экспериментальные факторы**; периодическую стратегию нельзя отождествлять с импульсным законом.
2. Величина эффекта изменяется при f>k=6, но исследованные точки не устанавливают порог устойчивости. Требуется независимый план вариации k и f.
3. Доверительные свидетельства и метрики риска синтетические, не откалиброваны на реальных атаках. Решающее правило не использует истинный сигнал, но его ошибка в эксперименте оценивается по известному генератору эталону.
4. При сетевом моделировании, пространственно неоднородных событиях, разделении сети, отказах доставки и Sybil полученные численные зависимости не доказаны.
5. Bootstrap интервалы условны относительно фиксированного набора сценариев; поведенческие эффекты exploratory, без независимого holdout; статистические утверждения не следует переносить на произвольные объекты инфраструктуры.
6. Перспективное направление — неоракульная диагностика полезности репутационного взвешивания с явным обнаружением смены режима и конкурирующим сравнением с комбинированным E1.
