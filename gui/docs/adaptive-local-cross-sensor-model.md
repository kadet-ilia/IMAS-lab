# E1-А. Этап 13: причинные перекрёстные измерения при отказе собственного датчика

**Дата:** 17.11.2026. **Версия:** e1a-causal-remote-sensor-f-hull-1.0.0.
**Статус:** исследовательская скалярная модель, включение только
plantCrossEnabled=true. Исходная модель E1 и предыдущие режимы объекта
при plantCrossEnabled=false не изменяются.

## Постановка и дополнительные физические допущения

В отличие от ранее реализованного обмена соседскими **предложениями**,
новый канал моделирует отдельную физическую измерительную аппаратуру
каждого отправителя j, способную независимо наблюдать состояние x_i
другого агента i при наличии непосредственного физического ребра
графа в такте s. Это сильное **дополнительное предположение**:
из исходной топологии информационной сети такая наблюдаемость
автоматически не следует. Для честного измерителя:

    y_(j→i)(s)=Π_[−S,S](x_i(s)+v_(j,i)(s)), |v_(j,i)(s)|≤V_cross.

Измеритель скомпрометированного отправителя может сообщить любое
значение из [−S,S]. Подлинность идентификатора источника и отметки
времени, доверенность исполнительных команд и граница V_cross
честного измерителя являются предпосылками сертификата.
Модель не охватывает подмену этих границ или захват исполнительного
контроллера. Состав нарушителей известен только генератору
воздействий и постфактум аудиту. Наблюдатель получает заранее заданную
публичную верхнюю границу f_max=plantCrossFaultBudget, независимую от
меток нарушителей; корректность условна при фактическом числе
компрометированных источников не выше f_max.

## Причинная доставка и прогноз

Сообщение, созданное в конце такта s, принимается не раньше
s+plantCrossDelay. Учитываются физические ребра на такте отправки
и доставки, потери plantCrossLoss, TTL plantCrossTTL и конечная
пропускная способность. На каждом такте из единой ёмкости C
резервируется C_cross=floor(C·plantCrossBandwidthFraction), тогда
как штатные локальные сообщения располагают C−C_cross.
Превышение C не допускается; неиспользованная фиксированная квота
не заимствуется (преднамеренно консервативная схема).
Данные от ранее аутентифицированного отправителя могут оставаться
в локальном архиве до истечения TTL при изменившейся топологии;
это не новое физическое измерение.

Полученное y_(j→i)(s) задаёт исходный интервал
I_(j,i)(s)=[y−V_cross,y+V_cross].
Для сравнения с состоянием x_i(t) при t>s он переносится только
по реально исполненным собственным командам u_i(k):

    L(k+1)=a·L(k)+b·u_i(k)−W,
    H(k+1)=a·H(k)+b·u_i(k)+W,  k=s,...,t−1.

На конечном такте интервал пересекается с [−S,S]. Никакая истинная
траектория x_i(k) и никакая метка нарушителя не используется при
переносе или слиянии интервалов.

## Робастное интервальное слияние

Для m различных аутентифицированных источников, из которых
не более f_max могут быть скомпрометированы, корректное x_i(t)
лежит в **не менее чем** q=m−f_max из m полученных интервалов.
При m≤f_max новые данные не дают сертифицируемого сужения.
Иначе определяется множество допустимых значений

    Q(t)={x∈[−S,S]: Σ_j 1[x∈I_j(t)] ≥ m−f_max}.

Поскольку Q может состоять из нескольких несвязных интервалов,
для непрерывного робастного барьера используется **внешняя
интервальная оболочка** hull(Q), а не безосновательное усечение
выбросов. Новый сертификат

    X_i(t|t)=X_i^own(t|t) ∩ hull(Q(t)).

Все интервалы замкнуты. Для скалярной задачи экстремумы Q
проверяются в конечном множестве концов поступивших интервалов;
сложность текущей реализации O(m²). В безопасном случае m>f_max
не менее q честных датчиков обязаны содержать реальное состояние
в пределах своих заявленных ошибок, следовательно реальное x_i(t)
содержится в Q(t) и в его оболочке. Если Q пуста или пересечение
с собственным сертификатом пусто, система переходит в
certification_lost, не заменяя неопределённость выдуманным точным
измерением. Сужение лишь по одной возможной комбинации источников
запрещено.

Обязательные ограничения: аппаратная возможность перекрёстного
наблюдения, независимые добросовестные границы измерения, достоверная
привязка источников, ограниченное число скомпрометированных
идентификаторов, известная модель объекта и журнал команд.
Без них гарантии **не действуют**. Подтверждение того, что
интервал содержит истинное состояние, пока доказано лишь
при этих допущениях для скалярного объекта и должно отдельно
проверяться независимым вычислительным оракулом.

## Программа верификации

- tests/gui/adaptiveLocalCrossSensing.test.mjs — причинное
  распространение по времени, подделка одного источника,
  дублирование, граничная осуществимость;
- tests/gui/adaptiveLocalCrossIntegration.test.mjs — замкнутый
  физический объект, распределение общей полосы,
  неизменность отключённого режима;
- tests/python/test_local_cross_sensor_reference.py —
  независимый пересчёт по архиву фактически доставленных
  пакетов и исполненных команд, без JS-формул;
- npm run adaptive:local:cross:pilot — поисковый факторный план:
  две топологии × две длительности отсутствия собственного датчика
  × включение/отключение перекрёстного наблюдения
  × три политики управления × три seed = 72 эпизода.
  Все преждевременные остановки учитываются безусловным штрафом
  λ=10; контролируются парные возмущения и общий бюджет.
  Оценка статистической значимости и переноса на аппаратную
  систему не заявляется.

Следующий научный шаг: подтвердить обоснованность геометрии
перекрёстного измерения для конкретного объекта, независимую
калибровку верхней границы V_cross, практический механизм
аутентификации источника и заранее зарегистрированную
подтверждающую серию при достаточном числе независимых реализаций.
