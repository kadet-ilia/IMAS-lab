# E1-А. Рискоориентированное адаптивное взвешивание коллективных решений

Дата: 16.11.2026. Статус: **новая экспериментальная гипотеза**; математические свойства ограничены приведёнными предположениями. Ветвь: `IMAS_Lab_test`.

**Алгоритм**: `adaptiveRiskController.js`, `adaptiveDecisionEngine.js`.
**Версия контроллера:** `e1a-risk-prequential-1.0.0`.
**Режим:** `alphaMode="risk_aware"`.
**Контрольный вариант:** `alphaMode="adaptive"` — исходная эвристика из предыдущих 3360 прогонов, сохранённая без изменения.

## 1. Причины изменения алгоритма

Завершённые синтетические исследования E1-А показали неоднозначное действие доверительного взвешивания. Для некоторых постоянных атак полезны сильные репутационные веса, а при ускоряющихся экспоненциальных и параболических воздействиях их использование может ухудшать RMSE. Критерий должен оценивать ожидаемую *полезность* доверительных весов только по наблюдаемому потоку сообщений. Нельзя выбирать коэффициент на основании эталонного решения x* или истинных принадлежностей агентов к нарушителям.

Важно: ранее полученные данные уже участвовали в выборе *концепции* контроллера. Поэтому новая серия с новыми seed — независимая проверка имитационных реализаций, но **не полностью независимое обоснование научной гипотезы**.

## 2. Задача с ограниченной наблюдаемостью

При такте t доступны вектор фактически доставленных предложений x(t), репутации r(t) на начало такта, маски доставки a(t) и предшествующая история. После усечения и ограничения получаются две оценки:

  y_T(t) = (Σᵢ τᵢ(t) x̃ᵢ(t))/(Σᵢ τᵢ(t)),
  y_W(t) = (Σᵢ τᵢ(t) wᵢ(t) x̃ᵢ(t))/(Σᵢ τᵢ(t)wᵢ(t)),

с последующей проекцией на безопасный интервал S. Медиана доставленных сообщений m(t) и её MAD служат суррогатами доступного группового контекста. **Медиана не является эталонной истиной** и может быть искажена координированной атакой.

Предлагаемая дополнительная наблюдаемая задача: какой из двух агрегаторов в прошлом лучше согласовывался с последующим состоянием набора предложений? Это не то же самое, что оценивать ошибку относительно x*.

## 3. Причинная предиктивная невязка

На шаге t≥2, имея *решения предыдущего шага* и *текущую медиану*, рассчитываются ограниченные ошибки:

  ℓ_T(t) = min[L²,((y_T(t−1)−m(t))/s_t)²],
  ℓ_W(t) = min[L²,((y_W(t−1)−m(t))/s_t)²],

где s_t = max(s(t),s(t−1),10⁻⁶)>0, s(t) — регуляризованный MAD, L — максимальный модуль нормированной невязки. Выражения измеряют *одношаговое согласование с последующей наблюдаемой медианой*, а не фактическую ошибку оценки неизвестного состояния.

Экспоненциальная память:

  R_T(t) = βR_T(t−1)+(1−β)ℓ_T(t),
  R_W(t) = βR_W(t−1)+(1−β)ℓ_W(t),

для 0≤β<1 после первой пары наблюдений; при первой паре R_T=ℓ_T и R_W=ℓ_W. Число допустимых предиктивных пар n_t фиксируется. Нельзя оценивать текущую пару по ещё не сформированному m(t+1) и нельзя переносить незавершённую пару через такт, на котором решение отсутствовало.

## 4. Коэффициент рискоориентированного выбора

После накопления n_t≥n_min допустимых пар:

  q(t) = [R_W(t)−R_T(t)]/[R_W(t)+R_T(t)+ε],

где ε>0 — регуляризация; −1≤q≤1. Отрицательный q означает, что взвешенная оценка в прошлых *предиктивных* парах показывала меньшую невязку.

  g(t) = [1−tanh(κq(t)/2)]/2,  κ≥0.

При n_t<n_min используется фиксированное g(t)=p₀∈[0,1]. Итоговый коэффициент:

  α(t) = h(t)·u(t)·g(t),
  h(t)=min(1,H(t)/H_min),
  u(t)=min(1,N_eff(t)/[θN_K(t)]),

где H(t) — число предшествующих завершённых шагов, N_eff — эффективный размер доверительно-взвешенной выборки, N_K — эффективное количество остающихся наблюдений, θ∈(0,1]. Реализовано жёсткое ограничение α∈[0,1].

Решение y_A(t)=Π_S[(1−α(t))y_T(t)+α(t)y_W(t)].

В отличие от исходной эвристики отсутствует прямой штраф за текущее расхождение |y_T−y_W|. Историческое предиктивное согласие может позволять α больше исходного, когда доверительное взвешивание действительно выигрывает по суррогатному критерию, либо уменьшать α при противоположном сигнале. Эта способность *не гарантирует* снижения действительного RMSE относительно x*.

## 5. Фиксированные параметры исследовательской версии

| Параметр | Значение | Интерпретация |
|---|---:|---|
| β | 0,85 | коэффициент памяти оценок |
| κ | 5 | чувствительность функции переключения |
| n_min | 4 | минимальное число последовательных оценочных пар |
| L | 8 | ограничение относительной ошибки |
| ε | 0,05 | регуляризатор суммы потерь |
| p₀ | 0,5 | начальное смешивание |
| γ, H_min, θ | 1; 8; 0,75 | параметры существующей доверительной обработки |

Параметры выбраны как **фиксированные инженерные эвристики**. Они не оптимизировались по эталонным ошибкам прежней подтверждающей серии. Исследование чувствительности и независимая калибровка по данным реальной системы остаются отдельными задачами.

## 6. Доказуемые свойства и границы

1. В условиях корректных численных входов 0≤α(t)≤1. Следовательно, при обеих оценках в безопасном выпуклом интервале итоговое решение также принадлежит ему.
2. Контроллер не содержит аргументов x*, bᵢ (истинные метки), будущие сообщения или истинные ошибки. На шаге t его состояние определяется исключительно предшествующими оценками и медианой сообщений, доступных к началу текущего расчёта. Изменение сообщений при шагах j>t не может изменить вычисленное α(t), если программная модель исполнения детерминирована.
3. Взаимно однозначная перестановка индексов агентов с сохранением пар (xᵢ,rᵢ) не влияет на α при отсутствии побочных зависимостей алгоритма свидетельств от индекса.
4. При отсутствии решений внутренний счётчик шагов продвигается, незавершённая предиктивная пара исключается. Отдельные потоки прогонов и сравниваемых методов не обмениваются состоянием контроллера.

**Недоказанное:** превосходство по RMSE, робастность при атаках большинства, точная статистическая калибровка риска, гарантия ограничения истинной ошибки, ISS полной ИМАС, безопасность автономного переключения при систематическом дрейфе истинного сигнала.

Нельзя трактовать q как апостериорную вероятность компрометации, а g — как вероятность правильного выбора. В частности, взвешенное решение может хуже согласовываться с медианой при честном меньшинстве с лучшими датчиками, а хорошо согласовываться с медианой при согласованной атаке большинства.

## 7. Программа проверки

Для каждого прогона выполняются *два* расчёта E1 с одинаковыми экзогенными событиями, исторической политикой доверия и одними входными параметрами; α различается между режимами `risk_aware` и `adaptive`. По каждому шагу проверяется совпадение контрольных решений `trimmed_unweighted` и `proposed_robust`. Новые seed не совпадают с ранее опубликованными испытаниями.

План: 72×30 парных прогонов в факторной разведочной серии и 12×100 парных прогонов с новыми seed в условно проверочной серии. Основной контраст: RMSE(risk_aware)−RMSE(adaptive), меньше нуля означает выигрыш нового контроллера. Дополнительно вычисляются контрасты с обычным усечённым и исходным комбинированным методами. Для статистического вывода используются парные разности целых прогонов, стратифицированный bootstrap и корректировка Холма для семейства ячеек. Применимость двустороннего sign-flip требует обменности знаков ошибок при нулевой гипотезе.

**Важно:** проверочные факторные конфигурации частично использовались в прежнем исследовании, поэтому новая серия не является полноценной внешней валидацией. Необходимо отдельно исследовать случаи изменения истинного состояния объекта, корреляции ошибок честных агентов и взлома опорной медианы.

Исходный вычислительный архив 3360 прогонов остаётся зафиксированным по собственному SHA-256; менять его задним числом для представления нового метода нельзя.
