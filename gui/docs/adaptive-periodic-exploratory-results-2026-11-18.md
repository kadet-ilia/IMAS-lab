Первичная величина: `ΔRMSE=RMSE(regime_aware_discrete)−RMSE(proposed_robust)`. Отрицательная разность предпочтительна; величина 0,01 рассматривается как предварительный ориентир практической значимости, а не эмпирически калиброванная стоимость ошибки.

## 2. Основные результаты

| Оцениватель относительно combined E1 | Среднее ΔRMSE по 80 ячейкам | Улучшение | Ухудшение | Равенство | Практически существенное ухудшение ≥0,01 |
|---|---:|---:|---:|---:|---:|
| исходный adaptive | **+0,010297** | 32 | 48 | 0 | 22 |
| risk_aware | **+0,007194** | 34 | 46 | 0 | 34 |
| regime_aware_discrete | **+0,000003** | 0 | 1 | 79 | 0 |

Это описательное усреднение по заранее установленным параметрическим ячейкам. Оно **не является** оценкой среднего эффекта для произвольного распределения реальных кибератак.

Результат `risk_aware−adaptive`, рассчитанный по 1600 попарно согласованным модельным прогонам: **−0,003102**. По `pulsed`-стратегии −0,004166, по `coordinated` +0,001155. Следовательно, частичный выигрыш risk_aware над старой адаптацией **не означает** выигрыш над сильным комбинированным контролем E1.

При f=6 среднее `ΔRMSE(risk_aware−E1)` = −0,000047; при f=12 = **+0,014436**. Это условное сравнение по двум значениям f, а не математическое доказательство порогового закона.

## 3. Фундаментальное ограничение нового дискретного режима

Из **1600** полных прогонов в **1599** ни одного переключения эксперта не зафиксировано. Только один прогон (`coordinated__pulsed__single__f12__corr0`, индекс 9) содержал два переключения; итоговые выборы в остальных случаях сохраняли контрольный E1. Для всех 64 `pulsed`-ячеек (**1280 прогонов**) переключений нет вообще.

В частности, точно нулевая средняя разность между regime_aware_discrete и E1 в **79 из 80** конфигураций отражает в первую очередь **неиспользование нового экспертного механизма**, а не эффективность поиска режима/адаптивного переключения.

**Научное заключение:** действующий пороговый механизм, критерий качества свидетельств и правило сброса статистики создают консервативную политику, часто удерживающую исходное E1. Необходим самостоятельный исследовательский механизм, доказывающий ценность переходов между оценивателями на причинных данных. Текущие результаты **не** дают оснований понизить гистерезис или переподобрать коэффициенты на ранее использованном holdout.

## 4. Постэкспериментальная проверка фактической интенсивности атаки

Независимо пересчитана по первой трассе каждого из 80 фиксированных сценариев фактическая доля тактов `attack_intensity>0`, а не только номинально заданные закон и период.

- 16 из 64 сценариев стратегии `pulsed` имели **0 активных атакующих тактов**. Это следствие несовпадения временного расписания `double` (окна 9–16, 25–32) и периода поведенческой стратегии P=16 (атака приходится на другие такты). Эти конфигурации нельзя использовать как доказательство качества алгоритма против активно воздействующего противника.
- В 48 остальных `pulsed`-сценариях число активных тактов равно 2, 4 или 8; 16 контрольных `coordinated`-сценариев содержат 8 или 16 активных тактов. Таким образом, **интенсивность и продолжительность фактического воздействия неодинаковы** даже при близких номинальных параметрах.
- Если рассматривать **только 48 конфигураций `pulsed` с действительным воздействием**, средняя ΔRMSE `risk_aware−E1` = **+0,007286**, `adaptive−E1` = **+0,011822**, `discrete−E1` = **0**.
- В 16 `pulsed`-сценариях без реализованной атаки соответствующие числа: **+0,007882; +0,010938; 0**. Нулевая интенсивность атаки не означает отсутствие шумов/ошибок базовой системы.

Это **постэкспериментальная диагностика**, а не изменение заранее зафиксированного первичного результата. Состав 80 ячеек и исходная сводка остаются неизменными; варианты с нулевым воздействием сохраняются в архиве и помечаются отдельно для оценки применимости полученных выводов.

## 5. Ограничения вывода и следующий этап

1. Представленные результаты относятся исключительно к зафиксированному синтетическому генератору событий, 30 агентам, T=48 и наблюдаемым свидетельствам, без сетевых ограничений.
2. Корреляция свидетельств в настройке генератора **не** является измеренной корреляцией реальных источников и не калибрует достоверность доверия.
3. Числа выигрышей и проигрышей по ячейкам нельзя считать независимыми статистическими испытаниями общей гипотезы. Допущения sign-flip не доказаны, интервалы индивидуальных ячеек не скорректированы на множественность.
4. Прежний `regime_aware` **не** дорабатывался на основе результатов поискового исследования; до любых изменений обязателен отдельный новый тренировочный протокол.
5. Далее исполняется уже заранее зафиксированная независимая по seed и новой совместной модели воздействия подтверждающая стадия (16 ячеек ×80 повторений, закон `linear`, расписание `sustained`). Её результаты запрещено использовать для подгонки версии 1.0.0.
6. Система на данном этапе не демонстрирует доказанную многомерную устойчивость ИМАС, византийский консенсус, доверенную корреляцию полевых свидетельств или приемлемое быстродействие в реальной инфраструктуре.
