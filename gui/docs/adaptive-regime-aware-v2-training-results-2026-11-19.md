## Основной результат

Среднее по заранее фиксированным равновзвешенным ячейкам, \(\Delta RMSE=RMSE(\text{исследуемый})-RMSE(E1_\mathrm{combined})\). Отрицательное число соответствует меньшей условной ошибке.

| Метод | Средняя ΔRMSE | Ячеек с улучшением | Ячеек с ухудшением | Совпадение с E1 |
|---|---:|---:|---:|---:|
| Исходный adaptive | **+0,006897** | 26 | 22 | 0 |
| risk_aware | **+0,004314** | 25 | 23 | 0 |
| regime_aware v1 | **−0,000027** | 2 | 0 | 46 |
| regime_aware v2, дискретный | **−0,000048** | 3 | 0 | 45 |
| regime_aware v2, смешивание | **+0,001376** | 26 | 22 | 0 |

**Технический порог существенного эффекта в протоколе — 0,01** абсолютных единиц RMSE; наблюдаемое снижение дискретной v2 по всем 48 ячейкам меньше этого ориентира примерно в 208 раз. Этот ориентир не является прикладно откалиброванной стоимостью ошибки.

В среднем число переключений дискретной v2 по полным прогонам равно 18/576=0,03125; переключение произошло в **18** отдельных прогонах. Для v1 — 10/576. Сравнение числа переключений показывает изменение динамики, но не доказывает способность обнаруживать кибератаку. Для режима blend счётчик дискретных переключений не определяет непрерывное изменение весов и в данной реализации не служит мерой динамики смешивания.

## Зависимость от заданной синтетической стратегии

Средняя разность по каждому из трёх классов поведения, на новых seed:

| Стратегия | ΔRMSE v2 discrete | ΔRMSE v2 blend | ΔRMSE risk_aware |
|---|---:|---:|---:|
| coordinated | 0 | +0,001864 | +0,007608 |
| pulsed | 0 | +0,002728 | +0,008231 |
| stealth | **−0,000144** | −0,000464 | −0,002898 |

Внутри stealth выражен один условный локальный эффект, например \`stealth__pulsed__sustained__behavior_linked__f12\`: средняя ΔRMSE дискретной v2 **−0,001677** (11 из 12 прогонов с переключением). Этот размер далёк от порога 0,01 и находится в **поисковом**, а не независимом подтверждающем наборе. По нему нельзя настраивать алгоритм и затем использовать ту же выборку как доказательство успеха.

При f=6 средняя ΔRMSE v2 discrete=0; при f=12 **−0,000096**. Это лишь описательный эффект взаимодействий в искусственно заданной модели.

## Методологическое решение

1. Изменения v2 сохраняются в выделенном режиме, исторические v1 и E1 неизменны.
2. Не утверждать практического выигрыша v2 или вывода о новых законах реальной киберустойчивости на основании поиска.
3. Не выбирать удачные \`stealth\`-сценарии для целенаправленного изменения гиперпараметров без нового тренировочного протокола.
4. Выполнить заранее определённую внешнюю модельную проверку \`linear/double\` на **12 ранее не просмотренных ячейках** ×60 парных повторов ×5 методов (3600 запусков) со строго тем же SHA расчётных исходников и математического плана.
5. По итогам проверки раздельно публиковать полный результат, худшие условия, числа переключений, безусловную потерю и причины невозможности обобщения на реальные угрозы.
