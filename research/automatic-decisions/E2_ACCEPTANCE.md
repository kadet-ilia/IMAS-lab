# E2.19 — матрица научной и программной приёмки
Экспериментальная ветка IMAS_Lab_test; исходное ядро статьи неизменно. Статус внедрения не равен успешному тесту. Актуальный протокол CI привязан к конкретному коммиту.

| Критерий | Доказательство / способ проверки | Ограничение |
|---|---|---|
| Воспроизведение статьи | e2:parity; первичные частоты и сравнение Python/JS | Исходная постановка |
| Обобщённые экстремумы | check-e2-extended.mjs / check-e2-next.mjs | Численная проверка малых задач и отдельных границ, не исчерпывающая |
| Динамические модели | dynamicNext.test.mjs / независимый DP и календарь событий | Статические скрытые состояния, фиксированные генеративные законы |
| Байес, CRC/PAC | finalStudies.test.mjs / Beta-квантили, симплекс, пороги | Различные типы статистических утверждений |
| Неполные наблюдения | finalStudies.test.mjs / SciPy оптимизация, границы завершения, отсутствие утечки | Идентифицируемость и предпосылки тестового закона |
| Браузер | verify.mjs / verification.json | Проверка рабочих сценариев на малых входах |
| Ресурсоёмкость | e2-memory.json из изолированных процессов Node | Не измерение браузера, не статистика повторов |
| Полевые данные | Пользовательский размеченный независимый набор, протокол происхождения и разбиения | Не предоставлены; критерий открыт |
| Эксплуатационная безопасность | Проверка предпосылок, реальной матрицы потерь, регламента операторов, проверка устойчивости на данных | Не подтверждена |
| Научная новизна | Независимая экспертиза, сравнение с литературой, доказательство новых зависимостей | Не устанавливается автоматическими тестами |

Не допускать автоматической маркировки стенда как научно принятого по зелёному CI. Для внешнего эксперимента требуются: описание объекта, размеченные состояния X, состав агентов и их бинарные наблюдения с признаками отсутствия, временные отметки, документированная стоимость решений, происхождение и ограничения выборки, заранее зафиксированный протокол калибровки и теста. Синтетический пример не является полевой проверкой.
