# E2.31: планировщик, первая реализация
Два независимых задаваемых фактора из prior, c, m, rhoScale, drop. Полная сетка до 15x15, случайный равномерный план и Latin Hypercube до 1000 различных точек, до 2000 расчетных единиц с повторениями. Для целочисленного M применяется округление, дубли конфигураций запрещены; свойство LHS относится к непрерывному пространству до округления. Зерно дизайна отдельно от зерна каждой единицы. Варианты ядра: M6 точная, MC M6/M7, межгрупповой стресс, активный DP, замкнутая СМО. Остальные параметры берутся из панели; для нескольких моделей специализированные настройки пока фиксированы значениями по умолчанию. Каждая единица — независимая калибровка и тест, если модель предусматривает тест. Независимость подразумевает математическую генеративную постановку; PRNG детерминирован.

Выполнение волнами через 1–4 Web Workers. Результаты упорядочены по плану независимо от завершения потока. Контрольная точка — последняя полностью записанная волна. При остановке незавершенная волна пересчитывается. Хэш конфигурации, версии и записей проверяется существующим механизмом IndexedDB. При изменении конфигурации прежние результаты не подменяют новые. Отдельно ограничивается суммарная ресурсоёмкость. JSON содержит исходный план через конфигурацию, единицы, зерна, первичные компактные данные и агрегаты. CSV содержит строки по политике и повтору. Средние и СКО рассчитаны отдельно по конфигурациям и политикам, не объединяются в безусловный эффект. Сертификаты относятся к отдельной постановке, не являются одновременной гарантией по всей сетке. Для межгруппового стресса номинальные границы отмечаются неприменимыми. Первые 500 строк показываются в таблице, полный массив в экспорте.

Дальнейшие работы: отдельное хранение единиц вместо перезаписи всего массива, импорт завершенных серий, многофакторные и Sobol-планы, адаптивное планирование, полный архив среды, автоматическое исследование гипотез, локальный вычислительный backend. Программные тесты не заменяют внешнюю валидацию.
