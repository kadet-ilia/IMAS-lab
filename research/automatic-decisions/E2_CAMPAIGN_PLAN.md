# E2: вычислительная кампания
До получения результатов фиксируется план: 128 различных наборов входных параметров в каждом из восьми подразделов (1024 конфигурации), 64 первые — поисковая часть, 64 последующие — проверочная часть с отличными зернами. Не считать сравниваемые политики и факторные уровни дополнительными конфигурациями. Все входы синтетические; действующие вычислительные модули стенда импортируются без дублирования. Зерно 20261126, распределения и ограничения явно заданы в gui/scripts/e2-campaign.mjs. Фиксированные сравнения, описательные средние, медианы, диапазоны, знаки эффектов, раздельные половины. Никаких утверждений о статистической значимости для генеральной совокупности или новизне по отношению к литературе только по этим данным.

| Раздел | Сравнение |
|---|---|
| Общее | S1–S8; M6 и M7 ниже и выше критического порога; прирост уточнённого сертификата, нарушение риска |
| Монте-Карло | Обычная и значимая выборки на общей калибровке; точная масса пропусков и ложных реакций; среднеквадратичная ошибка и ширина интервалов |
| Чувствительность | Парное 2×2 исследование зависимости и пропусков; знак взаимодействия; дополнительно пять политик Байес/CRC/PAC/M6 |
| Устойчивость | Нулевой стресс и регулируемые шесть механизмов; необменность при равномерной маске как отрицательный контроль |
| Оптимизация | Три конфигурации с одинаковым количеством агентов: равномерная, неоднородная, единая группа; критерии сертификации и затраты |
| Динамика | Четыре стратегии калибровки при сдвиге/без сдвига, три стратегии оптимальной остановки |
| СМО | Общие потоки, постоянный порог и обратная связь; потери, отказы, автоматизация, очередь; независимый предел риска |
| Данные | 64 задачи выявления скрытых групп на независимых подвыборках, 64 задачи неполной калибровки (MCAR/MNAR), общий тест и полная калибровка как синтетический контроль |

Проверочные метрики, предпосылки, первичные частоты и параметры сохраняются в JSON-артефактах GitHub Actions. Для воспроизведения из gui: node scripts/e2-campaign.mjs campaign-results. Отдельная проверка отложенной половины не заменяет заранее зарегистрированный эксперимент на независимом внешнем наборе.


## Дополнительная проверка после первой серии
Первичная серия 45840121350 завершилась успешно. Для отделения следствий конкретной модели от более общих свойств запланирована новая серия 128 конфигураций с новым корневым зерном 20261127, расширенными диапазонами априорной вероятности, цены эскалации, корреляции, пропусков и объёма калибровки. Сравнение двух условных законов (общий шок и бета-биномиальный), двух политик (M6 и идеальная байесовская при известном законе), одинаковые четыре точки факторного плана. Проверяются знаки контрастов, включая контрпримеры; отрицательный контраст не считается законом за пределами проверенного диапазона. Первая кампания повторяется с прежними зернами для более точного вывода малых ошибок и дополнительных расчётов на тех же данных: сравнение EM с EM на полной калибровке, сравнение границ завершения на полной и неполной, декомпозиция потерь при перегруппировке. Повтор прежних конфигураций не увеличивает число уникальных экспериментов.
