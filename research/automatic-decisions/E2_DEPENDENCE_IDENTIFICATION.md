# E2.21–E2.22: расширение робастной модели

## E2.21. Остаточная зависимость
Пусть Q_x — условный совместный закон полных счётчиков, q_gx — его маргинали. Предполагается TV(Q_x, ⊗q_gx) ≤ ε. Это внешнее ограничение, не оценка зависимости по данным. На событии одновременного L1-калибрования ||q_gx−qhat_gx||₁ ≤ r_gx получаем по сопряжению и неравенству треугольника

TV(Q_x, ⊗qhat_gx) ≤ D_x = min(1, ε + 1−∏_g(1−r_gx/2)).

Для наблюдения y при номинальной независимой доставке фиксированного размера условное ядро h(j)=∏_g H_g(y_g|j_g). Вероятность размера маски сокращается при расчете posterior. Для произвольной ограниченной h справедливо |E_Q h−E_P h| ≤ TV(Q,P)(max h−min h). Поэтому произведения маргинальных нижних и верхних экстремумов расширяются на ε osc(h) и пересекаются с [min h,max h]. На малых задачах дополнительно пересекаются с точными линейными экстремумами по внешнему совместному TV-шару D_x вокруг эмпирического произведения. Алгоритм переноса массы точен для этого шара; пересечение интервальных оболочек не есть точное решение исходной задачи с фиксированными маргиналями. Для больших пространств используется только масштабируемая оболочка. При ε=0 воспроизводится исходная независимая область (с точностью вычислений); для одной группы остаточная зависимость равна нулю.

Тестовый закон — смесь произведения истинных маргиналей и общего квантильного сопряжения с весом η. Его TV относительно произведения ≤ η. Если η≤ε, предположение о зависимости выполнено для данной генеративной модели. При η>ε выполнение не подтверждено, но нарушение не доказано. Истинная TV может быть меньше η. Калибровка фиксируется для всех η в одном повторе. Сравнение независимой M6 и M6+TV на общем тестовом законе: автоматизация, риск, ошибки, ширина posterior, попадание истинного posterior, масса нарушения порога и масса нарушения предпочтения. Точное суммирование или независимый MC (Hoeffding для отдельных конфигураций, условно по калибровке). При нестационарности, MNAR тестовой доставки или неизвестном приоре гарантия не переносится автоматически.

## E2.22. Частичная идентификация
Для фиксированных класса x и группы обозначим J полный счётчик, S событие полной доставки, p=P(S=1|x), s_j=P(S=1|J=j,x), z_j=P(S=1,J=j|x)=q_j s_j. Допущение чувствительности: odds(s_j)/odds(p) ∈ [1/Γ,Γ] при Γ≥1. При p=0,1 используются непрерывные предельные значения. Это ограничение именно полной доставки, а не отдельных сообщений. При Γ=1 S независимо от J внутри класса; неполные маски все еще могут зависеть от J. При Γ>1 допускается ограниченная информативность полной доставки.

Калибровочные частоты полной доставки и совместного события S=1,J=j доступны даже при неполных наблюдениях. Одновременно ограничиваются истинные вероятности полного счётчика, z_j и p. Для K=2Σ_g(n_g+1), B групп, M_x строк класса используется h_x=sqrt(ln(2(2K+2B)/α)/(2M_x)). Объединенная граница Hoeffding требует iid строк в классе; латентные эмпирические частоты ограничиваются детерминированными границами завершения. Из p∈[p_L,p_U] следует
s_L=p_L/(p_L+Γ(1−p_L)),
s_U=Γp_U/(1−p_U+Γp_U).
Из z_j∈[z_Lj,z_Uj] следует q_j≥z_Lj/s_U при s_U>0, q_j≤z_Uj/s_L при s_L>0; иначе соответствующее ограничение не добавляется. Пересечение с границами завершения и симплексом содержит истинный закон с вероятностью ≥1−α при выполнении предпосылок. При пустом пересечении сужение отменяется для группы и класса, выводится флаг несовместимости. Непустота не подтверждает модель пропусков. Увеличение Γ ослабляет дополнительные ограничения; при непустых областях с одинаковым бюджетом концентрации интервалы вложены.

Сравниваются точечный EM, M6 с границами завершения и M6 с дополнительными ограничениями. Обе робастные политики используют одинаковый более строгий бюджет ошибок, а не сравниваются с предыдущей версией границ при другом α. Тестовые метки не используются при подгонке. Приор оценивается по обучению, поэтому полевой сертификат не заявляется. Апостериорный расчёт по-прежнему требует номинального тестового ядра и независимости групп. Неполные данные не позволяют сами по себе установить Γ. Метод не является полной моделью MAR/MNAR.

## Воспроизводимость
В Устойчивости выберите «Робастная межгрупповая зависимость (TV)», L1, ε, число уровней η и объем MC для больших задач. В Данных выберите «Неполные: частичная идентификация», Γ и загрузите набор. Автоматическая группировка при неполной калибровке отключена. Экспорт JSON включает частоты, параметры, диагностические флаги, границы и результаты. Модульные и браузерные проверки входят в verify-2027.yml; статус зависит от конкретного коммита.
