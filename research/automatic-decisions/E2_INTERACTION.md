# E2.20: взаимодействие зависимости и пропусков
## Точная постановка
Условно независимые группы. Внутри группы обменные бинарные оценки. Для каждого класса X, размера n и заданного u формируется закон J. При положительной абсолютной корреляции rho модель общего шока смешивает Bin(n,u) с распределением на 0,n, а бета-биномиальная модель использует a=u(1-rho)/rho, b=(1-u)(1-rho)/rho. В предельных точках rho=0 и 1 используются независимость и общий шок соответственно. Для отрицательной корреляции только первый тип закона смешивает Bin(n,u) с двухточечным распределением минимальной дисперсии на floor(nu),ceil(nu). Нижняя допустимая граница rho_min=(frac(nu)(1-frac(nu))/(nu(1-u))-1)/(n-1). При детерминированных маргиналях или n=1 корреляция не определена и закон от rho не меняется. Недопустимые отрицательные значения отклоняются. Этот выбор отрицательного закона не охватывает все обменные законы с такой корреляцией.

Для каждой rho, delta точное интегрирование по (m_g,k_g). M6 калибруется на истинном синтетическом законе в каждой точке rho; один поток псевдослучайных чисел на повтор, одинаковые калибровочные частоты на всех delta при фиксированной rho. Идеальный Байес знает истинный закон, минимизирует потери с эскалацией и служит недостижимым в эксплуатации эталоном. При равенстве минимальных рисков выбирается первое действие, поэтому доля автоматизации зависит от правила разрешения равенств.

Контраст в соседней клетке: I=R(rho_hi,delta_hi)-R(rho_hi,delta_lo)-R(rho_lo,delta_hi)+R(rho_lo,delta_lo). Вычисляется только для четырех завершенных точек одного повтора. Оба контраста экспортируются отдельно; карта показывает среднее по полным клеткам, знак отдельных контрастов сохраняется. Положительные значения не скрываются и являются кандидатами в контрпримеры. Порог численного нуля 1e-10 условных единиц. Не заявляется одновременная статистическая гарантия на всю сетку.

## Аналитический частный случай
Одна группа из трех агентов, u_0=e, u_1=1-e, 0<e<1/2, prior=1/2, b=f=1, d=0, c>=1/2, общий шок rho∈[0,1], MCAR независимая доставка. Для m=0 риск 1/2, для m=1,2 риск e (при двух доставленных равенство голосов), для m=3 риск (1-rho)(3e²-2e³)+rho e. Поскольку m~Bin(3,1-delta),

R=e+(1/2-e)delta³-(1-rho)e(1-e)(1-2e)(1-delta)³.

Отсюда смешанная производная -3e(1-e)(1-2e)(1-delta)²<0 при delta<1, а прямоугольный контраст I=e(1-e)(1-2e)(rho_hi-rho_lo)[(1-delta_hi)³-(1-delta_lo)³]<0 при строгих интервалах. Результат ограничен этой байесовской постановкой, не относится автоматически к M6.
