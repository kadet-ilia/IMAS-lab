# Расширенный раздел «Автоматические решения»: методики и ограничения

Автор раздела: Ушаков И.А. Ветка IMAS_Lab_test. Эталон статьи E2-article-20261126-v1 не заменяется.

## Общая модель
1–20 групп, 2–50 агентов в группе; условный закон полного счётчика — смесь биномиального закона и общей оценки (корреляция ρ). Доставка MCAR с вероятностью 1−drop. Группы условно независимы, за исключением явно заданного стресса. Номинальная модель и тестовый закон разделены. Точный расчёт ограничен 300000 конфигураций; имитационный использует только групповые таблицы. Граница L1 и уточнение через первый порядок обобщены на B групп. Риск фиксированной политики сверху ограничен R_nom + L_max D, где D — взвешенная по классам TV-граница произведения групповых законов; граница обрезается по L_max. При нарушении предпосылок сертификат номинален. Новое ядро использует b>d и f>d, 0<π<1.

## Неопределённость
- L1: радиус из мультиномиальной концентрации с объединением по 2B законам; оптимум переносом массы.
- Покомпонентная: Хёффдинг по всем вероятностям, оптимум заполнением нормированного симплекса.
- W1: нормированная метрика |i−j|/n; DKW даёт r_W. Максимум ограничивается сверху любым двойственным значением λr+Σ_i p_i max_j[h_j−λd_ij]. Выбирается минимальное найденное значение; численный поиск не выдаётся за точное LP. TV≤min(1,n r_W).
- Обратная KL: D(q̂||q), метод типов с радиусом ((n+1) ln(M+1)+ln(2B/α))/M. Для ν>max h weighted AM–GM даёт h·q≤ν−exp(Σ_i p_i ln(ν−h_i)−r). Минимизация численная, верхняя оценка консервативна. TV≤sqrt(r/2).
- Моменты: ограничения на E[J/n] и E[(J/n)^2], радиус Хёффдинга sqrt(ln(8B/α)/(2M)). Двойственная функция max_j(h_j−λ1 t_j−λ2 t_j²)+λ1 m1+λ2 m2+r(|λ1|+|λ2|) даёт верхнюю оценку; численный поиск консервативен. Для TV используется 1, поэтому сертификаты могут быть тривиальны. Сопоставление при одном α не означает одинаковую геометрию и консервативность. Байесовские доверительные/credible и конформные среднерисковые гарантии не отождествляются с условным риском M6.

## Эксперименты
Общее: все серии статьи и первичные данные NumPy.
Монте-Карло: M6/M7, S1–S8, одна калибровка, отдельное зерно теста, заранее заданные контрольные объёмы и одновременные Hoeffding-интервалы; состояние PRNG сохраняется каждые 5000 запросов.
Чувствительность: одна или две оси π, c, M, масштаб ρ, пропуски; повторности с общими зернами, поточечные t-интервалы (приближение), контраст относительно первой точки по обеим осям. Соболь/Jansen: независимые равномерные π,c,ρ,drop; A/B и AB_i. Моррис: p=4, Δ=2/3, случайные направления и перестановки, μ, μ*, σ. Оба глобальных метода условны относительно фиксированного калибровочного зерна; малые N дают неточные оценки, индексы Соболя не обрезаются до [0,1]. Сравнение пяти семейств на одних калибровочных данных. Масштабирование от 1 до 20 групп: точное и MC время одного запуска, число ячеек таблиц вместо недостоверных измерений heap/RSS.
Устойчивость: интенсивность η от 0 до 1. Сдвиг u первой группы при X=1 к 0,45; доля общей квантильной компоненты η; доставка положительных/отрицательных сообщений от исходной к 0,35/0,75; необменность с равномерной маской (инвариантность счётчика); необменность + смещённая маска (смесь исходного ядра и k=min(m,j)); загрязнение калибровочного закона противоположным крайним счётчиком. Последние два — отдельные синтетические механизмы, не доказательство всех форм MNAR/необменности. Необменность представлена смесью равномерного расположения единиц и упорядоченного при заданном J; при общей равномерной маске её эффект на агрегированные счётчики равен нулю.
Оптимизация: B и одинаковое n перебираются на конечной сетке, свойства групп берутся циклически из базовой конфигурации. По одному независимому калибровочному зерну на кандидата; α делится на размер сетки. Требования: нижняя граница γ и верхняя граница совокупного риска; проектные затраты B*c_group+B*n*c_agent. Фронт Парето по минимальным затратам/верхнему риску и максимальной нижней автоматизации. Не подтверждённая точка не обязательно недопустима; слишком большая точка не оценивается. Многоальтернативная серия: JSON-спецификация priors, u, losses (3–6 классов, 2–8 действий; размер u K×B, losses A×K), L1 по классам с α/(KB), нормированное множество весов. Максимум дробного линейного риска находится бисекцией знака Σ w_i(L_i−r). Сравнение с точечным эмпирическим и истинным Байесом, условные MC-интервалы.
Динамика: фиксированная калибровка, периодическое скользящее окно, перекалибровка по сигналу; истинные метки и полные счётчики доступны через задержку не ранее следующего запроса. Сдвиг u первой группы при X=1. Сигнал по разности нормированных средних с объединённой Hoeffding-границей на горизонт; α_t=α/(T+1) для окон при стационарном iid законе. При сдвиге гарантия не переносится. Последовательная серия раскрывает вложенные подмножества до полного наблюдения: первая рекомендация, полное наблюдение, первый допустимый M6; стоимость ожидания линейна. Это сравнение политик, не оптимальная остановка или POMDP. Для последовательного режима drop не используется.
СМО: λ_op=λ(1−γ), ρ=λ_op/(sμ). Эрланг C и Wq, Lq при ρ<1; иначе стационарных значений нет. FCFS M/M/s: независимые экспоненциальные интервалы и обслуживания, исключение первых warmup запросов. Временная средняя длина очереди получается интегрированием интервалов ожидания; среднее ожидание по поступившим после разогрева запросам, в том числе если обслуживание началось позже конца горизонта. Поэтому остаток закона Литтла на конечном горизонте не обязан быть нулевым. Дедлайн относится к ожиданию, а не завершению обслуживания. Динамической обратной связи цены эскалации пока нет.
Данные: локальный JSON {"schema":"imas-e2-observations-v1","groups":[2,2],"source":"описание","synthetic":false,"rows":[{"time":1,"x":0,"agents":[[0,1],[0,0]]}, ...]}. time — числовая строго возрастающая отметка, x — истинный бинарный класс; агенты 0,1,null. Минимум 20 строк, максимум 50000 и 10 млн агентных значений. Калибровочная часть хронологически первая, полная и с обоими классами; тест не влияет на частоты/приор. Корреляции условно по X (до 100 агентов), разброс маргиналей и доля пропусков; не устанавливают независимость или идентификацию MNAR. Тестовые Hoeffding-интервалы доступны при явном iid-допущении, сертификат внешней модели не заявляется. Источник и синтетическая маркировка задаются пользователем; происхождение не подтверждено автоматически. Экспорт не включает исходный файл целиком, только его хеш, разбиение, частоты, тестовые решения и метрики.

## Воспроизводимость и приёмка
Все новые серии имеют Web Worker и JSON/CSV. Ключ контрольной точки включает версию, режим и параметры; содержимое SHA-256. Сохраняются законченные расчётные единицы; длительная отдельная единица при остановке пересчитывается. MC сохраняет RNG и гистограммы по пакетам. Смена вкладки размонтирует интерфейс, повторный запуск с теми же параметрами восстанавливает серию. Импортируемые данные не сохраняются без явного экспорта. Время измеряется в текущем браузере и зависит от устройства.
Модульные проверки: совпадение с ядром статьи при одинаковых входах, нулевой стресс, нормировка, двойственные границы, 1000 агентов, план факторного дизайна, Парето, M/M/1, задержанные метки, многоклассовые риски, отсутствие утечки тестовых меток, воспроизведение MC после контрольной точки. Браузерная проверка охватывает все восемь вкладок и JSON. Программная верификация не равна доказательству научной новизны и внешней адекватности. Полевая валидация, оптимальная остановка, обратная связь очереди и адаптивная оценка структуры групп требуют дальнейшего самостоятельного исследования.


## E2.9–E2.12: продолжение расширения
**Независимая проверка.** extended_reference.py использует гипергеометрические вероятности SciPy, linprog для L1/box/транспортных/моментных задач, явное перечисление конфигураций и вершин многоклассового множества, прямую формулу Эрланга C. check-e2-extended.mjs передаёт только конфигурации и результаты для сравнения; проверка входит в CI. В первоначальной серии 312 проверок; наибольшее абсолютное расхождение 2,18e-9. Это ограниченная численная проверка, не доказательство всего расширенного аппарата. Двойственная оценка моментного множества проверяется на консервативность, не на равенство LP.

**Расширенный MC.** Классический подраздел S1–S8 сохранён. Кнопка «Расширенный Монте-Карло» открывает обобщённую модель. Число групп 1–20, размер 1–50, до 1000 агентов; выборка до 2 млн на калибровку. Отдельные зерна для каждой калибровки и тестовой имитации. В предложении меняется только распределение X; условные законы неизменны, w_x=π_x/π'_x. Оценки являются обычными невырожденными взвешенными средними, не самонормированными. Они могут внести выборочную погрешность за пределы физического диапазона; доверительные границы ограничиваются физическим диапазоном целевой величины. Для автоматизации и потерь используется Хёффдинг с диапазоном w_max и w_max L_max. Для пропуска и ложного реагирования событие имеет один постоянный вес; инверсия бинарной KL-границы даёт консервативный интервал, в том числе при нуле событий. Уровень ошибки делится на R×2×4×ceil(Nmax/batch). Остановка — только при заранее заданных объёмах, когда максимальное отклонение от обеих границ по долям и по потерям, нормированным Lmax, не превышает допуска. Допуск 0 отключает досрочную остановку. Сохраняются завершённые калибровки; прерванная калибровка пересчитывается. Точное сравнение M6 при размере до 300000; M7 оценивается имитационно. Интервалы условны относительно случайных калибровок; повторности не дают автоматически доверительного интервала генерального среднего. Выборка по классу не гарантирует эффективности для редких ошибок внутри класса.

**Выявление групп.** В Данных включается отдельным флагом. Первая часть обучения выявляет граф по условной взаимной информации в битах. Вторая, более поздняя, часть используется для калибровки обеих политик и диагностики остаточных зависимостей; третья — одинаковый независимый тест. Полная связь объединяет группы, если минимальная попарная связь не ниже порога и размер не превышает установленный предел. Компоненты связности объединяют по цепочкам связей. Одиночные группы не сливаются принудительно. До 100 источников и 50 млн парных операций на выборку. Если найдено больше 20 групп или группа больше 50, граф экспортируется, расчёт новой политики не выполняется. CMI — эмпирическая попарная оценка, не доказательство обменности или совместной условной независимости. При переключении структуры тестовые метки не используются. Доверительные интервалы при флаге iid относятся к отдельным политикам.

**Неоднородный проектный поиск.** В Оптимизации выбирается «Неоднородные конфигурации». JSON-список до 100 объектов с groups и необязательными name,u,rho,costs. Каждая строка — заданный кандидат; не заявляется оптимум по не перечисленным вариантам. При числе конфигураций до 300000 применяется точная модель. Для больших пространств при включённой опции оценивается номинальный закон на независимой имитации; по половине α/K отведено калибровке и имитации. Односторонние границы Хёффдинга для двух показателей с объединением: h=sqrt(log(2/α_MC)/(2N)). Нижняя граница γ=max(0,γ̂_nom−h−D), верхняя граница R=min(L_max,R̂_nom+L_max(h+D)). D — верхняя TV-граница для произведения калибровочных групповых законов. Риск и автоматизация истинного синтетического тестового закона не заполняются номинальными оценками. Все кандидаты и основания статуса экспортируются. Сравнение кандидатов, не прошедших ограничение, не доказывает их недопустимость.


## E2.13–E2.16: динамика, активные наблюдения и замкнутая СМО
### E2.13 — взвешенная калибровка
Четыре политики: начальная фиксированная, длинное скользящее окно, экспоненциальное забывание, переключение между длинным и коротким окном по сигналу. Полные групповые счётчики становятся известны только с истинной меткой после заданной задержки, не ранее следующего запроса. Для каждого X ведётся отдельная последовательность. Вес наблюдения i из окна длины W: w_i=β^(W−1−i); p_hat(j)=Σ_i w_i 1[J_i=j]/Σ_i w_i. Эффективный объём N_eff=(Σw)^2/Σw². Для iid стационарного закона взвешенная концентрация Хёффдинга по непустым собственным подмножествам даёт радиус L1 min(2, sqrt(2 ln[(2^(n+1)−2)·2B/α'] / N_eff)). α'=α/[4(T+W+1)]: объединение по четырём заранее заданным схемам (включая начальную) и конечным позициям каждой условной последовательности до горизонта; выбор короткого или длинного окна после сигнала не нарушает эту поправку. При сдвиге оценка — эвристика, не сертификат нового закона. Сигнал: разность средних J/n для первой группы класса X=1 между начальной калибровкой и коротким окном. Порог — сумма двух Hoeffding-радиусов с объединением по конечным позициям. Сравниваются пары серий без сдвига и с заданным сдвигом на общих зернах; ложная тревога означает хотя бы один сигнал до сдвига (или в любой момент в нулевом режиме). Задержка обнаружения и доля обнаружений относятся к первому сигналу не ранее сдвига, если не было более раннего сигнала. Частоты по конечному числу повторов описательные; для точной оценки малых вероятностей ложной тревоги нужно больше повторов. Модель не оценивает неизвестную задержку меток и предполагает доступ к полным счётчикам после метки.

### E2.14 — конечный POMDP и активное получение сообщений
Скрытое состояние (X,J_1,...,J_B) статично в пределах запроса; переход тождественный. Достаточная статистика истории запроса (m_g,k_g), число раскрытых и положительных оценок. Условная номинальная вероятность класса пропорциональна π_x ∏_g Σ_j H_{m_g,k_g,j} q_hat_gx(j); условный закон J_g пропорционален H q_hat_gx. При запросе одного случайного нераскрытого члена группы g вероятность Y=1 равна Σ_x P(x|m,k) E[(J_g−k_g)/(n_g−m_g)|x,m,k]. Приращение m_g=1, k_g=Y; запрошенный член не используется повторно. Группа выбирается активно или по фиксированному циклическому правилу (наименьшее m_g, при равенстве первый индекс). Терминальные автоматические действия разрешены только по M6 с независимым порогом safetyRisk; эскалация всегда доступна по номинальной цене c. V(s)=min{c, допустимый номинальный риск, min_g [queryCost+(1−p_g)V(s_g0)+p_g V(s_g1)]}. При исчерпании бюджета ветви запроса отсутствуют. Динамическое программирование с мемоизацией вычисляет номинальный минимум для заданного горизонта и допустимых действий; это не робастный минимакс по всему дереву. При номинально невозможном наблюдении используется эскалация. Нулевой бюджет совпадает с немедленной политикой; активный номинальный минимум не больше циклического. Эмпирические потери на общем синтетическом тестовом законе могут отличаться от номинальных. Ограничения: до 8 групп, 12 запросов, грубая верхняя граница 3 млн состояний; параметр drop не используется. Активность относится к группе обменных членов, не выбору индивидуально неоднородного агента. Смена X и J внутри запроса не моделируется.

### E2.15 — замкнутая динамическая очередь
Нестационарный пуассоновский поток с тремя интервалами: базовый, пиковый, базовый. Независимые экспоненциальные требования обслуживания заранее генерируются для каждого запроса; общий поток и сообщения для сравниваемых политик, истинный X используется только в расчёте потерь. Операторы одинаковые, приоритет невытесняющий по верхней границе вероятности угрозы; FIFO внутри приоритета. Ёмкость относится только к ожидающим, отказ при заполнении; истечение дедлайна означает прекращение ожидания, а не прерывание обслуживания. При совпадении времени завершения с дедлайном ожидающего сначала удаляется истекший запрос. Измерение загрузки и длины очереди — интеграл по заданному горизонту после разогрева, исходы запросов этого интервала доводятся до завершения или отказа после горизонта. Среднее Wq относится к обслуженным. Для запроса c(t)=c+gain·w_proxy(t), где w_proxy=0 при свободном операторе, иначе (Q+1)/(sμ). Это наблюдаемый приближённый индекс ожидания, не точное прогнозное Wq. Автоматическое действие допускается только при M6 с порогом min(c(t),safetyRisk), так что перегрузка не отменяет независимый предел риска. Реализованные потери: L(a,X) для автоматического решения, отдельная фиксированная queueOperatorLoss+queueWaitCost·W для обслуженного, failureCost+bX+queueWaitCost·W для отказа или тайм-аута. Экономическая цена обслуживания не изменяется при поиске базового порога c. Отказы и тайм-ауты учитываются раздельно; unsafe — счётчик нарушений алгоритмического допуска, а не доказательство реальной безопасности. Стационарная формула Эрланга сохраняется отдельным режимом; не применяется к данной нестационарной системе.

### E2.16 — совместный проектный поиск
Конечная сетка (s,c,gain), до 200 расчётных единиц вместе с повторностями. Одни и те же зерна калибровки, заявок, сообщений и требований обслуживания внутри повтора для всех кандидатов. Критерии: минимум s·operatorCost, средних потерь и доли отказов, максимум автоматизации. Эмпирические ограничения на три последних показателя задаёт пользователь; Парето строится среди полных эмпирически допустимых и подтверждённых статистическими границами вариантов. Для каждого непустого повтора рассчитываются средние по запросам этого повтора, затем равновесное среднее по повторам; не объединять коррелированные запросы как iid. При R независимых повторах и K кандидатах односторонний радиус Хёффдинга h=sqrt(ln(3K/α)/(2R)), верхняя граница потерь использует Lmax=max(b,f,d,queueOperatorLoss+queueWaitCost·deadline,failureCost+b+queueWaitCost·deadline). Нижняя граница автоматизации max(0,γhat−h), верхние границы отказов min(1,Fhat+h) и потерь min(Lmax,Lhat+Lmax·h). Цель — ожидание показателей по непустым имитационным сериям при заданной генеративной модели. При неполной серии или пустом измерительном интервале подтверждение не выдаётся. Границы при малом R широкие; эмпирическая допустимость отдельно от подтверждения. Номинальные калибровочные допуски не являются одновременной эксплуатационной гарантией по всей сетке. Глобальный оптимум вне сетки, независимая полевая проверка и реалистичные параметры операторов не заявляются.
