# E2.23, E2.25, E2.30: мониторинг и статистическое оценивание

## Мониторинг
Фиксированная M6 обучается на отдельной калибровке. Независимый номинальный эталон содержит доставленные наблюдения и метки, а не скрытые полные счётчики. Диагностические признаки в [0,1]: доля доставки, положительных сообщений и автоматизации при поступлении запроса; после получения метки — условные по X групповые доли k/n и m/n, квадраты k/n, попарные произведения, нормированные потери фиксированной M6 и её автоматический вклад. Набор признаков фиксирован до мониторинга. Это тесты отдельных средних, а не исчерпывающий тест равенства совместных законов. Отсутствие сдвига признаков не доказывает адекватность.

Для F признаков эталонный интервал Hoeffding [l,u] использует h=sqrt(ln(4F/α)/(2N)); пустой эталон даёт [0,1]. При iid номинальном потоке событие одновременного покрытия имеет вероятность ≥1−α/2 условно по фиксированной политике. Для классовых признаков учитывается фактический размер эталона класса; iid и фиксированная задержка меток позволяют рассматривать отдельный классовый поток. Не предполагается независимость разных признаков.

Детектор окна использует заранее фиксированные размеры w и не более H=steps позиций, h_w=sqrt(ln(4FHW/α)/(2w)), где W число размеров. Сигнал при выходе среднего за [l−h_w,u+h_w]. Объединенная вероятность ложной тревоги ≤α за горизонт при стационарности.

Для верхнего отклонения e-фактор exp(λ(Z−u)−λ²/8), нижнего exp(λ(l−Z)−λ²/8), λ∈{.25,.5,1,2,4,8}. По Hoeffding при верном эталоне каждый процесс — неотрицательный супермартингал относительно своего потока. Усредняются 12 вариантов и H заранее равновероятных стартов, не начавшиеся компоненты равны 1. Рекурсия для суммы начавшихся компонент S_t=(S_{t−1}+1/H)*factor_t; остаток (H−t)/H. Вычисление в логарифмах. Неравенство Вилля и объединение по F дают вероятность ложного сигнала ≤α/2 дополнительно к эталонному бюджету. Уровень α действует отдельно для двух детекторов; для выбора любого из них постфактум нужен дополнительный бюджет.

При тревоге отзывается номинальный сертификат, флаг фиксируется до конца серии. Политики отзыва выполняют полную эскалацию; экспериментальная политика после e-сигнала использует постсигнальные аудиты с минимумом меток каждого класса и периодическим пересчетом. Аудит предполагает восстановление полного счётчика с фиксированной задержкой; в реальных системах это отдельная предпосылка. При новой калибровке сертификат НЕ восстанавливается. Признаки фиксированной политики продолжают измеряться независимо от текущей политики. Доступные немедленно признаки могут отозвать сертификат до решения по текущему запросу; метки поступают не ранее следующего запроса. Для стационарной гарантии требуются iid поток и независимый эталон, а для калибровки M6 — её исходные предпосылки. Селективные метки, неизвестная задержка и нестационарность требуют иной постановки.

## Редкие ошибки внутри класса
Для номинальных условно независимых групп исходный закон J|X известен в имитации. Формируется наклон q'_gx(j) ∝ q_gx(j) exp(θ_x j/n_g), θ_0=+θ, θ_1=−θ. Маска остаётся номинальной. Сравнение трёх предложений на общей калибровке: исходное, изменённый prior π', изменённый prior и защитная смесь δ Q_x+(1−δ) Q'_x полных групповых векторов (не произведение отдельных смесей). Для последнего веса
w = P(X)/P'(X) / [δ+(1−δ) ∏ q'_gx(J_g)/q_gx(J_g)].
Веса ограничены max(π/π',(1−π)/(1−π'))/δ. Обычная оценка N^-1 Σ w_i f_i несмещённая, может выходить за диапазон; интервал пересекается с физическими границами. Доверительные интервалы Hoeffding условны по калибровке, с поправкой по трём методам, четырём метрикам и всем повторам. Выводится SE по взвешенным значениям, ESS, средний и максимальный вес, число событий. Точный контроль при размере ≤300000. Не заявляется оптимальность наклона, преимущество по всем метрикам или применимость к неноминальным законам. Требуется отдельная оптимизация предложения для разных редких событий.

## PAC с эмпирической дисперсией
При фиксированном номинальном действии и сетке из K порогов Z_t=L(a*,X)1[r≤t] ∈ [0,Lmax]. Эмпирическая дисперсия V вычисляется по всем N наблюдениям, включая нули. По теореме 4 Maurer & Pontil, Empirical Bernstein Bounds and Sample Variance Penalization, COLT 2009, https://arxiv.org/abs/0907.3740, односторонняя граница после объединения по K:
U_B=min(Lmax, mean+sqrt(2V ln(2K/α)/N)+7Lmax ln(2K/α)/(3(N−1))).
Комбинированная граница — минимум Бернштейна с α/2 и Hoeffding с α/2, обе с поправкой по K. Выбирается максимальный допустимый порог; при отсутствии — эскалация, нулевой автоматический вклад. Гарантия каждого метода относится к среднему автоматическому риску, не к каждому решению; при постфактум выборе между методами нужна поправка. CRC и исходные политики сохранены.

## Пилотная программа
Сценарий gui/scripts/e2-monitor-campaign.mjs фиксирует 128 разных конфигураций на направление (384 суммарно), две половины 64+64. Мониторинг: парные потоки без сдвига и со сдвигом, четыре механизма, общий эталон. Редкие ошибки: три предложения, точный риск, RMSE и ESS. PAC: 7 политик на общем тесте и точная проверка среднего риска трёх PAC-порогов на истинном синтетическом законе. Это пилот, а не выполнение всей кампании 94720 расчетов, оценки описательные для заданных диапазонов. Целевой показатель 80% обнаружения не считается достигнутым без результатов по конкретному классу альтернатив.
