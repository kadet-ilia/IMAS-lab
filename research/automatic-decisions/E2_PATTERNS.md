# E2.32. Выявление закономерностей и контрпримеров
Анализ в подразделе «Серии экспериментов» выполняется только после завершения всего плана. Проверяются идентификаторы конфигураций, повторов, зерна, факторы, полнота и наличие конечных метрик. Для каждого повтора формируется парный выигрыш B относительно A (R_A−R_B для минимизируемого показателя, γ_B−γ_A для максимизируемого); вместо A допустим заданный порог метрики. Средний выигрыш по повторам образует одну единицу анализа. Повторности не считаются независимыми конфигурациями. Номинальные границы при явно нарушенных предпосылках не анализируются.

По фиксированному зерну конфигурации делятся на две непересекающиеся половины. На поисковой половине строятся однофакторные области по эмпирическим квартилям и их двухфакторные пересечения, а также вся область. Для правила задаются минимальный размер подгруппы n_min, практически значимый выигрыш δ≥0 и целевая доля успехов τ∈(.5,1). Успех: выигрыш > δ+10^-10. Правило допускается к ранжированию при среднем выигрыше >δ, доле успехов ≥τ и n≥n_min. До пяти лучших правил сортируются по доле успехов, среднему выигрышу, размеру подгруппы, простоте и детерминированному идентификатору. Все пороги замораживаются до оценки второй половины. На проверке выводятся n, средний, доля успехов, минимум/максимум и все случаи неуспеха (обратный эффект, нулевой, положительный ниже порога). Данные не скрываются при отрицательном результате.

Проверка уже выполненного пакета описательная: сетка/LHS не iid, повторный подбор настроек может использовать результаты обеих половин. Даже для случайного плана этот интерфейс не выдает p-значений. Экспорт анализа содержит параметры, условия, разбиение, контрасты, исходные факторы и зерна. Не универсальный закон, не причинный эффект, не подтверждение научной новизны.

Для отдельной проспективной кампании разрешен режим iidFresh только если правила зафиксированы по независимой поисковой выборке и новая выборка iid из заранее заданного генератора с независимыми повторностями, без отбора по результату. Для каждой фиксированной подгруппы при условии ее наблюдаемого размера n проверяется H0:P(выигрыш>δ|подгруппа)≤τ точным односторонним биномиальным хвостом. Недостаточные подгруппы получают p=1; поправка Холма применяется ко всем выбранным правилам, включая недостаточные. Перекрывающиеся подгруппы не требуют независимости p-значений для Холма. Это проверка доли успехов в заданном синтетическом генераторе, не проверка среднего эффекта, полевой применимости или универсальности. Контрпример к строгому утверждению может быть статистической флуктуацией при конечных повторностях; требует отдельного воспроизведения.
