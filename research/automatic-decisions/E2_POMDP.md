# E2.27–E2.28. Динамическая модель и индивидуальный выбор источников

## Постановка
Время дискретно, X∈{0,1}, начальный prior известен. P(1|0)=a, P(0|1)=b. До завершения запроса переходы не зависят от действий; защитное реагирование является терминальным. Доступны терминальные действия 0,1,2 (не реагировать, реагировать, эскалация), ожидание одного такта и однократный запрос конкретного агента i. Запрос занимает d_i целых тактов, требует цену c_i и цену ожидания за каждый такт. В промежутке новых решений нет. Наблюдение при доставке измеряет состояние в момент доставки, а не в момент отправки запроса. Вероятность доставки v_i не зависит от состояния; условно по текущему X вероятность Y=1 задается u_i0,u_i1. Условно независимые свежие измерения. В горизонте H обязательна остановка. Групповые калибровочные законы не используются. Параметры и интервалы заданы извне, статистическая гарантия не заявляется.

## Интервальная оболочка
a,b и u_ix принадлежат заданным интервалам (пересечение симметричных радиусов с [0,1]). Для текущего интервала вероятности I=[l,u] прогноз следующего состояния p'=(1−p)a+p(1−b), минимум и максимум по вершинам прямоугольника. Для d_i тактов рекурсивно применяем интервальную операцию. Байесовский posterior при доставке имеет вид p' q1/[(1−p')q0+p'q1]. Экстремумы вычисляются по вершинам, исключая нулевой знаменатель; мультиаффинное представление числителя и знаменателя дает отношение как взвешенную сумму отношений на допустимых вершинах. Если событие невозможно для всех вершин, используется [0,1], а ветвь имеет нулевую вероятность. При недоставке posterior равен прогнозу.

Терминальное автоматическое действие допускается только при строгом робастном предпочтении M6 и максимальном условном риске не выше safetyRisk. Эскалация всегда допустима. Стоимость эскалации сравнивается отдельно в целевой функции. Для запроса вероятность положительной доставленной оценки w лежит в [wL,wU], вероятность пропуска 1−v_i фиксирована. Верхняя оценка продолжения
U=c_i+d_i c_wait+(1−v_i)V_empty+max_{w∈[wL,wU]}[(v_i−w)V_0+wV_1].
Достаточно двух концов интервала. Для ожидания используется верхняя стоимость следующего узла. При выборе продолжения минимизируется U, для терминала берется max по I. В каждой истории условная вероятность и ветвевые posterior-области допускаются независимо, т.е. это прямоугольная внешняя оболочка, более широкая, чем множество траекторий фиксированного неизвестного закона. Поэтому U — консервативная верхняя граница риска полученной политики для каждого допустимого фиксированного закона и точное значение описанной релаксации, а не точное решение исходной не-прямоугольной minimax задачи.

Точное номинальное DP с тем же множеством разрешенных терминальных действий дает нижнюю границу minimax оптимума в этом классе политик, если номинальная модель принадлежит области. Разность U−V_nom ограничивает субоптимальность полученной робастной политики в этом классе. Это не сравнение с неограниченным POMDP. Для каждого выбранного дерева вычисляются точные математические ожидания на номинальном и одном фиксированном стресс-законе (верхний a, нижний b, верхние u_i0 и нижние u_i1). Стресс-закон лежит в интервалах, не обязательно является наихудшим.

## Сравнение
Немедленная робастная остановка; равномерный случайный выбор допустимого источника с робастным условием продолжения; циклический DP (первый доступный источник по порядку, также ожидание); жадный робастный выбор по одношаговому эффекту; номинальный DP; робастный DP. Все используют одну и ту же модель допуска. Отдельно рассчитываются потери решения, затраты запроса, стоимость ожидания, автоматизация, ошибки, ожидаемые число запросов и задержка, условные нарушения предела риска, частота запросов каждого источника. Для двух оптимальных политик экспортируются деревья. При нулевых радиусах номинальное и робастное DP совпадают по значению. Ограничения: H≤5, до 6 источников, максимум 100000 узлов; точный перебор историй без дискретизации posterior. Приближенные методы для больших горизонтов, неопределенность задержки и доступности, повторные запросы, управление динамикой защитным действием и коррелированные измерения еще не реализованы.

## Экспериментальная программа
Сценарий gui/scripts/e2-pomdp-campaign.mjs: по 128 различных конфигураций с изменчивостью скрытого состояния и с выраженной неоднородностью источников (64+64 в каждой области); математические ожидания вычисляются точно, не MC. Результаты отдельных задач и агрегаты сохраняются в артефакте CI. Это пилот, не полная кампания и не внешняя валидация.
