# Журналы запусков

Каталог заполняется автоматически. Для каждого задания сохраняется основной JSON-файл и, при наличии соответствующих данных, отдельные CSV-файлы:

- траектории одного прогона;
- пошаговая статистика Монте-Карло;
- bootstrap-сравнения;
- сводки распределений;
- сетевые показатели;
- главные эффекты и взаимодействия факторного плана.

Имена файлов имеют вид `run_<дата-время>_<сид>_<режим>`. Частично завершенные задания помечаются как `partial`.
